# Second-Monitor Hub — releases

This repository exists only to host **release artifacts and the update
manifest** for Second-Monitor Hub. There is no source code here.

The application source is in a private repository. This repository is public
so that the auto-updater and download links keep working: the updater fetches
`latest.json` from `releases/latest/download/`, which requires the assets to
be publicly readable.

## Downloads

Get the latest installer from the [Releases](../../releases) page:

- **Windows** — `Second-Monitor.Hub_<version>_x64-setup.exe`
- **macOS** — `Second-Monitor.Hub_<version>_universal.dmg`
